CARA MENGGUNAKAN PAKET INI
━━━━━━━━━━━━━━━━━━━━━━━━━━

LANGKAH 1 — HOST PRIVACY POLICY
Buka file privacy_policy.txt dan upload ke salah satu platform berikut
agar dapat diakses via URL publik:

  a) Google Sites (gratis):
     - Buka https://sites.google.com/new
     - Buat halaman baru, tempel isi privacy_policy.txt
     - Publish dan salin URL-nya

  b) GitHub Pages:
     - Upload privacy_policy.txt ke repo GitHub
     - Aktifkan GitHub Pages di Settings > Pages
     - URL: https://kdsmedia.github.io/castlekingdomseason/privacy_policy.txt

  c) Notion (gratis):
     - Buat halaman Notion baru, tempel konten
     - Publish ke web dan salin URL

LANGKAH 2 — SIAPKAN GRAFIS
Ambil semua file dari folder ALTOMEDIA/graphics/ dan simpan di komputer/ponselmu.
File-file ini akan diupload langsung ke Google Play Console.

LANGKAH 3 — UPLOAD KE PLAY CONSOLE
Ikuti instruksi detail di file upload_guide.txt (Bagian A sampai H).

LANGKAH 4 — ISI STORE LISTING
Salin teks dari store_listing.txt ke Play Console:
  - App Name → salin dari bagian "APP NAME"
  - Short Description → salin dari bagian "SHORT DESCRIPTION"
  - Full Description → salin dari bagian "FULL DESCRIPTION"

LANGKAH 5 — PUBLISH ARTIKEL BLOG
Gunakan konten dari blog_article.txt untuk:
  - Posting di blog/website ALTOMEDIA
  - Artikel di Medium atau Kompasiana
  - Konten untuk social media (potong menjadi bagian-bagian)
  - Press release untuk media game Indonesia
