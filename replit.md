# Castle Kingdom Season

A medieval tower defense mobile game for Android by **ALTOMEDIA**.

- **Package:** `com.altomedia.castlekingdomseason`
- **Unity Version:** 2021.3.45f2 LTS
- **Category:** Games > Strategy
- **Platform:** Android (Google Play)
- **GitHub:** https://github.com/kdsmedia/castlekingdomseason

## Project Structure

- `Assets/` — Unity project assets (animations, scripts, scenes, prefabs, plugins)
- `ProjectSettings/` — Unity project settings
- `ALTOMEDIA/` — Google Play Store release package (store listing, graphics, privacy policy, upload guide, blog article)

## About the Game

Castle Kingdom Season is a tower defense game where players defend a castle against waves of enemies across seasonal maps (forest, tundra, desert, swamp). Features archer/cannon/mage/lightning towers, multiple enemy types, and 3-star level scoring.

**Monetization:** Google AdMob / Unity Ads (optional rewarded ads)  
**Connectivity:** Offline capable
